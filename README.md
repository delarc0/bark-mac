# Bark for Mac

Native macOS dictation. Hold a key, speak, release — the transcribed text appears
at your cursor, in any app. 100% on-device: your audio never leaves your Mac.

## Install

```bash
git clone https://github.com/delarc0/bark-mac.git
cd bark-mac
./install.sh
```

`install.sh` checks prerequisites, builds from source, code-signs, installs to
`/Applications`, and launches. No Apple Developer account needed.

On first launch you'll grant two permissions (Microphone, Accessibility) and the
speech model (~1.5 GB) downloads once. Then hold **Right Option**, speak, and
release.

Handing this to a coding agent? Point it at [AGENTS.md](AGENTS.md).

## Requirements

- Apple Silicon Mac (arm64)
- macOS 14 (Sonoma) or later
- Full Xcode + [xcodegen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`)

## Features

- Hold-to-talk hotkey (default Right Option), fully rebindable
- Local Whisper transcription via [WhisperKit](https://github.com/argmaxinc/WhisperKit)
  (Neural Engine + GPU accelerated), model + language selectable
- Pastes at the cursor in any app; your clipboard is saved and restored
- Menu-bar overlay pill that reacts to your voice
- Text cleanup (filler removal, capitalization) and custom word replacements
- Feedback chimes, input-device picker, onboarding flow, in-app updates (Sparkle)

## Signing note

Bark self-signs (no Apple Developer ID yet). `install.sh` uses ad-hoc signing by
default, which works with zero setup but means macOS forgets your permission
grants whenever you rebuild. If you'll rebuild often, run
`./scripts/create-signing-cert.sh` once first — it creates a local self-signed
cert so grants persist across rebuilds. Details in [AGENTS.md](AGENTS.md).

## Development

`project.yml` is the source of truth; `Bark.xcodeproj` is generated by xcodegen
and gitignored. See [CLAUDE.md](CLAUDE.md) for architecture and the file map.

```bash
xcodegen && open Bark.xcodeproj   # work in Xcode
./install.sh                      # or build + install + launch in one shot
```
